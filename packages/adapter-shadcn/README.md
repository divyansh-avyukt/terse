# @terseui/adapter-shadcn

Renders Terse components as [shadcn/ui](https://ui.shadcn.com) components. Your app provides the components themselves (`pnpm dlx shadcn@latest add ...`).

```ts
shadcn({ ui: '@/components/ui' }) // import path of your shadcn components folder
```

Docs, spec and getting started: https://terse-ui.dev · Source: https://github.com/divyansh-avyukt/terse
