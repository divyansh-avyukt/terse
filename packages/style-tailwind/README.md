# @terseui/style-tailwind

Maps Terse style tokens (`gap=md`, `tone=muted`, `size=lg`, ...) to Tailwind classes. Add the package to Tailwind's sources so the classes are generated:

```css
@source "../node_modules/@terseui/style-tailwind/src";
@source "../node_modules/@terseui/adapter-shadcn/src";
```

Docs, spec and getting started: https://terse-ui.dev · Source: https://github.com/divyansh-avyukt/terse
